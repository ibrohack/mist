# Demo images

Covers and screenshots of the demo catalog, taken from the English Wikipedia articles of each game, where they are
published as non-free content under fair use. They are reduced to Wikipedia's size and converted to JPEG. Each one
belongs to the game's publisher. MIST uses them only as local demo data for a school project; do not redistribute
them. If a file is missing, `DemoData` draws a placeholder instead.
